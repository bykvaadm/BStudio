# Образец: как подключить презентацию к BStudio

BStudio нужны **две вещи**: картинки слайдов и файл с речитативом. Ничего конвертировать не надо.

Здесь лежит готовый рабочий урок на 4 слайда — открывай студию и записывай прямо сейчас.

## Раскладка

```text
example/                      ← «корень курса»: эту папку указываешь студии
└── lesson1/                  ← «урок» (их может быть сколько угодно)
    ├── 03-script.md          речитатив: что говорить на каждом слайде
    └── deck_frames/          картинки слайдов
        ├── p-01.png
        ├── p-02.png
        ├── p-03.png
        └── p-04.png
```

Свой урок делаешь так же: рядом с `03-script.md` кладёшь папку `deck_frames/` со своими PNG. Хоть 4 картинки, хоть 40.

## Запуск

Двойной клик по `studio-launch.command` → в студии указать папку `slides/example/` → выбрать урок `lesson1`.

Камера в браузере работает только через `http://localhost`, поэтому студия поднимается скриптом, а не открывается
двойным кликом по `studio.html`.

## Четыре правила, и всё

1. Папка урока — любая, но **файл речитатива обязан называться `03-script.md`**. Речитатив при этом
   **необязателен**: без него урок всё равно откроется, в списке будет помечен «без речитатива», а суфлёра не будет
   вовсе — ни окна с текстом, ни его кнопок. Слайды, камера и запись работают как обычно.
2. Картинки лежат в папке **`deck_frames/`** (рядом со скриптом или на уровень глубже).
3. Картинки называются **`p-01.png`, `p-02.png`, `p-03.png`…** — префикс `p-`, номер, `.png`. Файл с другим именем
   в набор кадров не попадёт. Если раскладывать по этому шаблону не хочется, годится **любая папка с картинками**:
   она встанет в список источников отдельным пунктом, порядок слайдов — по именам файлов.
4. **Число картинок = число слайдов в речитативе.** Склейка идёт по порядку: первый кадр к первому слайду, второй ко
   второму. Титульный слайд считается за один.

## Контракт речитатива (`03-script.md`)

| В файле | Что делает |
|---|---|
| `## Титульный слайд` | титульный слайд (первый кадр) |
| `### Слайд 1.1 — *описание*` | новый слайд. Нужны именно длинное тире `—` и курсив `*…*` |
| пустая строка | конец блока суфлёра — лектор берёт дыхание |
| `[P]` | короткая пауза внутри фразы |
| `**жирным**`, `` `кодом` `` | выделение в суфлёре |
| `<!-- meta:camera pos=4, size=26, shape=round -->` | как встать камере на этом слайде |
| строки с `#`, `>`, `---` | игнорируются — это заметки для человека |

Ключи `meta:camera`: `pos` (1–8), `size` (проценты или доля), `shape` (`round`/`rect`), `cam` (`on`/`off`),
`full` (`on` — камера на весь экран), `zoom`.

## Если что-то не так

- **«Не нашёл, что показывать»** — в выбранной папке нет вообще ничего рисуемого: ни `deck_frames/` с `p-NN.png`,
  ни PDF, ни картинок.
- **Слайды есть, суфлёр пустой или съехал** — число картинок не совпало с числом слайдов в скрипте. Пересчитай:
  титульный тоже считается.
- **Часть картинок не подхватилась** — имена не по шаблону `p-<номер>.png`.
- **Камера не включается** — студия открыта как `file://`. Запускай через `studio-launch.command`.

> Мелочь на будущее: если захочешь привязывать кадры к слайдам не по порядку, а по номерам, — положи в `deck_frames/`
> файл `manifest.json` вида `{"slides":[{"file":"p-01.png","id":"титул"},{"file":"p-02.png","id":"1.1"}]}`, где `id`
> совпадает с заголовками скрипта. Для обычной работы это не нужно.
